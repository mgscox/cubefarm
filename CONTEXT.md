# CubeFarm

CubeFarm coordinates research, planning, and issue-based engineering work across repositories.

## Language

**Idea**

A proposed change described by its problem or desired outcome. It may include hints about which CubeFarm floors to investigate.

**PRD**

The requirements document researchers prepare for an Idea. It describes the problem, proposed outcome, scope, and how to judge whether the outcome has been achieved.

**Review Round**

Two independent agent reviews of the same PRD revision, one focused on the evidence and requirements and the other on feasibility across floors.

**Proposal**

A specific pair of PRD and Issue Plan revisions presented together for a Manager Decision.

**Manager Decision**

The manager’s approval, rejection, or request for refinement on a Proposal. Approval authorizes publication of the Issue Plan in that Proposal.

**Issue Plan**

The breakdown of a PRD into implementation work for one or more configured floors selected by researchers. It distinguishes new issues from existing work and records any hierarchy and dependencies.

**Tracking Parent**

An issue that groups related implementation issues so their progress can be followed together.

**Publication**

The handoff of an approved Issue Plan to the issue workflow. It is complete when the issues and their relationships are verified and the new implementation issues have been released for normal scheduling.
