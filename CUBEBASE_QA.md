# Software factory QA

PR-Agent reviews pull requests and can post inline GitHub suggestions with proposed fixes. Check its review and suggestions during QA.

If you agree with a suggestion after checking it against the PR requirements and repository rules, you may apply it directly through GitHub's **Commit suggestion** action or make the equivalent edit on the PR branch. You can do this within QA without sending the PR back to the development agent for that fix.

Review the resulting diff, rerun the checks affected by the fix, and base your QA verdict on the resulting commit. Record which suggestions you applied and the verification results in your QA report. Use your normal QA judgment for any remaining findings.
